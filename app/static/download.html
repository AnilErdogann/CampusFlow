Windows kurulum dosyası şu anda indirilmeye hazır değil.

Windows 10/11 · Kurulumdan sonra Başlat menüsünden CampusFlow'u aç
◈

Android

Bu sayfayı Chrome'da aç. Menüden Uygulamayı yükle veya Ana ekrana ekle seçeneğine dokun.

◉

iPhone

Bu sayfayı Safari'de aç. Paylaş → Ana Ekrana Ekle yolunu izleyip Web Uygulaması Olarak Aç seçeneğini etkinleştir.

Telefon kurulumu için CampusFlow'un HTTPS kullanan bir adreste yayınlanması gerekir. Android ve iPhone'da kurulum web uygulaması olarak yapılır; bu sayfadaki .exe yalnızca Windows içindir.
